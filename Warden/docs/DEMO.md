# 90-second demo script

## Setup

- Laptop: open Warden locally.
- Phone: open the same Vite/tunnel URL.
- Keep the Raspberry Pi kit in view, but begin with the laptop companion in its neutral state.

## Narrative

**0–10 seconds — the premise**

“Robotics is the next interface to the physical world. But physical work still breaks down when somebody has to recognize a part, choose a connector, and prove it worked. Warden is an agentic hardware debugger that sees, speaks, and verifies.”

**10–30 seconds — phone-first interaction**

On the phone: “I have a Raspberry Pi and I want to connect my first sensor.” Open the phone camera when Warden asks.

**30–50 seconds — real-world awareness**

Show the Pi, Qwiic cable, and APDS9960. Ask: “Can you see it?” Warden identifies the visible evidence, including a clear label/address when legible, or makes a useful confirmation-seeking guess.

**50–70 seconds — shared build surface**

Point to the laptop. The architecture animates from confirmed source through the keyed cable to the target. The right column contains only the current action and verification—not a transcript or a tutorial.

**70–90 seconds — proof**

Use the live Pi bridge if available, or press **Run demo**. The sensor becomes visible at `0x39`; Warden marks the moment verified and advances.

## Closing line

“The point is not that Warden knows a Raspberry Pi demo. The point is that it turns ambiguous physical work into an evidence-backed next move—on the bench, in a lab, or eventually in the field.”
